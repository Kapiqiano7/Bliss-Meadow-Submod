# Bliss Meadow

**A custom location for Monika After Story inspired by the iconic Windows XP “Bliss” wallpaper.**

Bliss Meadow brings a familiar green hillside into MAS, with time-of-day backgrounds, a custom entrance sound, and a one-time first-visit conversation with Monika.

> This is an unofficial fan-made project. It is not affiliated with or endorsed by Team Salvato, the Monika After Story team, or Microsoft.

## Features

- Custom **Bliss Meadow** location for Monika After Story.
- Separate daytime and nighttime backgrounds.
- A sunset version created by applying MAS's sunset filter to the daytime image.
- Calendar hidden while visiting Bliss Meadow, so it does not appear to float over the outdoor scenery.
- Optional Windows XP-style startup sound when entering the location.
- A unique conversation with Monika on the first visit. The first-visit dialogue is queued only once; the entrance sound can play on later visits too.
- Entry handling preserves MAS's default background-entry behaviour.
- An entry in MAS's **Submods** list with the add-on name, author, version, and description.

## Compatibility

**Tested with:**

- Monika After Story **0.12.20**
- Ren'Py **6.99.12.4.2187**

This project uses the legacy Ren'Py/Python environment bundled with that MAS release. Compatibility with other MAS or Ren'Py versions has not been confirmed.

## Affection Requirement

The Location Selector becomes available at **400 affection (ENAMORED)**. You must reach this affection level with Monika before you can select custom backgrounds such as Bliss Meadow.


## Installation

1. Close Monika After Story.
2. Copy the `game` folder containing the two `.rpy` files, two `.png` backgrounds files and the `.wav` file into your main DDLC directory.
3. Start MAS. Ren'Py should compile the `.rpy` scripts automatically on launch.
4. Open **Hey, Monika... → Location → Can we go somewhere else?** and select **Bliss Meadow**. 

The add-on should also appear in the **Submods** list.

### Expected folder layout

```text
DDLC/
└── game/
    ├── submods/
    │   └── Bliss Meadow/
    │       ├── bliss_meadow.rpy
    │       └── bliss_meadow_info.rpy
    │
    └── mod_assets/
        └── location/
            └── bliss/
                ├── bliss.png
                ├── bliss-n.png
                └── windows_xp_startup.wav
```

The `.rpyc` files are generated by Ren'Py from the `.rpy` source files. They do not need to be included in the repository.

## Asset requirements

The scripts expect the following asset names and paths:

| File | Purpose |
| --- | --- |
| `bliss.png` | Daytime background |
| `bliss-n.png` | Nighttime background |
| `windows_xp_startup.wav` | Sound played when entering Bliss Meadow |

The backgrounds used during development were prepared at **1280 × 720**. Keep the filenames and directory structure exactly as shown above.

The audio file must be readable by the legacy Ren'Py version bundled with MAS 0.12.20. A standard PCM WAV file is recommended.

## Troubleshooting

### Bliss Meadow does not appear in the Location menu

- Check that both `.rpy` files are inside `DDLC/game/submods/Bliss Meadow/`.
- Check that the `bliss` asset folder is inside `DDLC/game/mod_assets/location/`.
- Make sure the image filenames match the names in the installation instructions.
- Confirm that MAS is using a compatible version.

### The sound does not play

- Check that the file is named exactly `windows_xp_startup.wav`.
- Check that it is located in `game/mod_assets/location/bliss/`.
- Make sure the WAV encoding is supported by the Ren'Py version bundled with your MAS installation.

### Ren'Py reports an error after editing the scripts

- Close MAS before editing files.
- Keep the `.rpy` source files; do not replace them with `.rpyc` files.
- If a compiled `.rpyc` becomes stale or corrupted, back it up and let Ren'Py regenerate it from the corresponding `.rpy` source on the next launch.
- Keep a backup of your MAS installation and persistent data before making changes.
